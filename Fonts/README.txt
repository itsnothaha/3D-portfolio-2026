Local font assets for the portfolio.

fonts.css declares Bagel Fat One, Grandiflora One, Indie Flower,
Just Another Hand, Rock 3D and Send Flowers. Assets are provided by
Google Fonts with a compact Latin/punctuation subset; Bagel Fat One
includes printable ASCII for headings, navigation and category labels. Matching *-LICENSE.txt files
contain each font's license. No external font requests are required.

If adding new languages or new heading text, update the appropriate
font subset to include the new characters.
